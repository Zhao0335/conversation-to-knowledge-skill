# Related work

This project complements knowledge-capture and retrospective skills by focusing on a different endpoint: turning completed work conversations into portable learning artifacts that a human can study and reuse.

Adjacent approaches include structured knowledge capture, single-session agent retrospectives, and longitudinal retrospective knowledge bases. `distill-conversation` is Markdown-first, destination-neutral, and emphasizes reusable explanations, procedures, decision records, failed paths, and boundary conditions.
